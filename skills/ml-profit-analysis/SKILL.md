# ml-profit-analysis — 利润分析

## 目的

算清一个候选品到底赚不赚钱：单件赚多少、三层利润各是多少、供应商必须给到什么条件才达标、价格或运费一变会怎样。本 Skill 只算公式，**不编任何费率**。所有百分比和成本都由用户提供或来自可见页面；没有可靠数据时用用户确认的假设做模拟，并标注“模拟结果，不代表实际费用”。

## 市场参数（market_code，第一位参数）

- `market_code` 必填，二选一：`MLM` = Mercado Libre México（墨西哥站，货币 MXN）或 `MLB` = Mercado Livre Brasil（巴西站，货币 BRL）。
- **如果 `market_code` 缺失，先问用户，不默认 MLM。** 绝不以“用户没说就按墨西哥”静默处理；用户明确要求巴西时，一律按 MLB 走。
- 货币：MLM 一律 MXN，MLB 一律 BRL。**三层利润公式本身与货币无关（currency-agnostic），但每一个输入和输出都必须标注其货币；绝不混用 MXN 和 BRL，绝不用自编汇率换算。** 跨市场对比时，两种货币并列呈现，换算写“待核实”，除非用户提供了汇率 + 日期。
- 货币列名对照：墨西哥用 `price_mxn / cost_mxn / …_mxn`，巴西用对应的 `price_brl / cost_brl / …_brl`；同一计算只用一套，绝不混用。
- 关键词语言：MLM 只用西语，MLB 只用葡语，绝不用中文关键词。

**费率事实状态（2026-11-23 核实，不要改写）：**

- 没有任何 Mercado Libre 佣金比例是经直接核实的。mercadolibre.com.mx 当日无法做文本抓取；第三方说法冲突（Clásica 8–17% 与 8–16% 不一，Premium 11–21.5% 与 12.5–20.5% 不一）。**平台费率 %、税费 %、广告 %、分期 % 一律是用户提供的输入，默认 0，未提供或未核实时写“待核实”，绝不 hard-code 一个区间当事实，也不把区间放进公式或示例当真数。**
- **以下税费事实仅限墨西哥站（MLM），巴西站不适用，巴西税费待核实**：唯一经核实的税费事实是 Mercado Pago 博客 2026-05-15（https://www.mercadopago.com.mx/blog/nuevas-retenciones-ventas-en-plataformas，2026-11-23 访问）：有 RFC 时每笔销售代扣 ISR 2.5%（按毛额）、IVA 代扣 8%（即 16% 总 IVA 的 50%）；无 RFC 时 ISR 20%、IVA 16%；自 2026-01-01 起 personas morales 同样为 ISR 2.5% / IVA 50%；外国居民在墨西哥无常设机构、或收款进境外银行账户时 IVA 代扣 100%。**这些是代扣（retenciones），可抵扣 / 暂缴性质，不是全部税费成本——不要把 8% IVA 代扣说成总 IVA 成本。**代扣的 CFDI 在次月前 5 天内开具。Mercado Pago 不代扣州税。**不要把上述墨西哥 ISR / IVA 费率、MXN 费用或 MSI 分期照搬到巴西；不要自编任何巴西佣金 / 税率。**
- **巴西站（MLB）税费**：税费 %（`tax-pct`）为用户提供的输入，**默认 0，待核实**；未提供时按 0 计算，并在输出里写“巴西税费待核实”，不编数。
- Mercado Ads Knowledge Hub（https://knowledgehub.academy.mercadoads.com/product-ads，2026-11-23 访问）：Product Ads 按点击付费（CPC），按 Ad Rank 竞价，可设目标 ROAS 和每日预算，预算不累计；要求声誉黄色以上、刊登 ≥15 天、至少 1 笔销售（企业）/ 10 笔（个人）。**没有公布 CPC 费率，也没有公布最低预算**——广告 % 只能由用户提供。
- 其他（低于 $299 的固定费、免费刊登额度、MSI 分档、声誉阈值、禁售清单）一律待核实，不写入公式或示例当事实。**其中低于 $299 的固定费、MSI 分档为墨西哥站语境，巴西站不适用，巴西对应费用待核实。**

## 输入

本 Skill **不直接调大麦 MCP**，只读上游价格和用户提供的数据。

| 输入来源 | 内容 |
|---|---|
| `market_code` | 必填：`MLM` 或 `MLB`。缺失时先问用户，不默认 MLM。货币：MLM 为 MXN，MLB 为 BRL。 |
| Skill 2（ml-product-discovery）/ Skill 3（ml-competitor-analysis） | 售价（MLM 为 MXN，MLB 为 BRL）、价格带 |
| 用户提供（必填） | 采购成本（市场货币/件）、头程（市场货币/件）、进口相关成本（市场货币/件，无则 0 并写待核实）、本地物流（市场货币/件）、仓储（市场货币/件）、包装（市场货币/件）、售后损耗（市场货币/件）、起订量 MOQ、总预算（市场货币） |
| 用户提供（百分比，默认 0） | 平台费率 %、税费 %、广告占比 %、分期占比 %、退货率 %。未提供时默认 0，并在输出里写“待核实”，不编数。**巴西站税费 % 为用户提供，默认 0，待核实。** |
| 用户提供（可选） | 目标利润率 %（反向推导用，默认 25%）、预期日单量（算资金回收周期用，没有则写待核实）、供应商报价（市场货币/件，用于对照最高可接受采购成本） |

**百分比的口径要写清**：税费 % 是用户提供的综合税费假设，还是仅指已核实的代扣（ISR 2.5% / IVA 8%）？两者不能混用。只填代扣时要注明“仅代扣部分，不是全部税费成本”。**ISR 2.5% / IVA 8% 代扣仅限墨西哥站（MLM），巴西站不适用，巴西税费待核实。**

## 脚本

算术一律交给脚本，不要心算。两个脚本都从 V2.1 移植（`~/workspace/custom-skills/mercado-libre-product-selection/scripts/`），公式见下。

### 单件速算：`scripts/profit_estimate.py`

**所有金额参数均为市场货币：MLM 为 MXN，MLB 为 BRL；同一计算只用一种货币。**

```text
python3 scripts/profit_estimate.py --price <市场货币> --cost <市场货币> --shipping <市场货币> \
  --fee-pct <平台费率%> --other <其他单件成本，市场货币> --return-pct <退货率%> \
  --ad-pct <广告%> --installment-pct <分期%>
```

公式：平台费 = 售价 × 平台费率%；退货成本 = 售价 × 退货率%；广告成本 = 售价 × 广告%；分期成本 = 售价 × 分期%；单件净利 = 售价 − 平台费 − 采购 − 运费 − 其他 − 退货成本 − 广告成本 − 分期成本；毛利率 = 单件净利 ÷ 售价 × 100%；盈亏平衡售价 =（采购 + 运费 + 其他）÷（1 − 平台费率% − 退货率% − 广告% − 分期%）。分母 ≤0 时盈亏平衡售价无解，写“无解（费率合计 ≥100%）”。**公式与货币无关，但售价、成本、单件净利、盈亏平衡售价输出时一律标注市场货币（MXN / BRL）。**

### 三层利润 + 反向推导：`scripts/operating_profit.py`

**所有金额参数均为市场货币：MLM 为 MXN，MLB 为 BRL；同一计算只用一种货币。**

```text
python3 scripts/operating_profit.py --price <市场货币> --procurement <市场货币> --first-leg <市场货币> \
  --import-cost <市场货币> --local-shipping <市场货币> --fee-pct <%> --tax-pct <%> \
  --warehousing <市场货币> --packaging <市场货币> --ad-pct <%> --installment-pct <%> \
  --return-pct <%> --after-sales <市场货币> --moq <件> \
  --target-price <市场货币> --target-margin-pct <%> --supplier-quote <市场货币> --total-budget <市场货币>
```

其中 `--tax-pct`：MLM 可填用户提供的综合税费假设，或仅限墨西哥站已核实的代扣（ISR 2.5% / IVA 8%，须注明仅代扣）；**MLB 的 `--tax-pct` 为用户提供，默认 0，待核实**，不要填墨西哥代扣费率。

## 三层利润（不要 lump 在一起）

**公式与货币无关；下表每一项金额输出时一律标注市场货币（MLM 为 MXN，MLB 为 BRL）。**

| 层 | 公式 |
|---|---|
| 商品毛利 | 售价 − 采购成本 − 头程 − 进口相关成本 |
| 经营贡献利润 | 商品毛利 − 本地物流 − 平台费用 − 税费 − 仓储 − 包装 − 广告成本 − 分期成本 |
| 预计净利润 | 经营贡献利润 − 退货退款成本 − 售后损耗 |

其中：平台费用 = 售价 × 平台费率%；税费 = 售价 × 税费%；广告成本 = 售价 × 广告%；分期成本 = 售价 × 分期%；退货退款成本 = 售价 × 退货率%。

现金流单独算：单件前期现金流出 = 采购 + 头程 + 进口 + 包装；首批现金流出 = MOQ × 单件前期现金流出。资金回收周期只有在有预期日单量时才算，没有时写“待核实”，不编一个日单量去算。

## 利润反向推导（先定目标，再问供应商行不行）

输入目标售价和目标利润率，反向算：

- 最高可接受采购成本 = 售价 − 平台费用 − 税费 − 本地物流 − 仓储 − 包装 − 广告 − 分期 − 退货成本 − 售后损耗 − 目标净利润 − 头程 − 进口成本。
- 最低可接受售价 =（采购 + 头程 + 进口 + 本地物流 + 仓储 + 包装 + 售后损耗）÷（1 − 平台费率% − 税率% − 广告% − 分期% − 退货率% − 目标利润率%）。分母 ≤0 时写“无解”。
- 最高可接受物流费用、最高可接受广告成本（金额与比例）、最高可接受起订量 = 总预算 ÷ 单件前期现金流出，向下取整。
- **供应商报价超过最高可接受采购成本时，必须原样输出这句话：“当前采购条件不符合目标利润要求。”**不要为了推荐商品而降低卖家的利润要求。
- 反向推导要和正向利润一起输出：正向算能赚多少，反向算供应商必须给到什么条件；两个方向对不上时，先判 CONDITIONAL（交给 Skill 6）。

## 压力测试（三情景，模拟假设，不是市场预测）

每个候选品至少分析乐观、基准、压力三个情景；每个情景输出单件净利润、净利率、盈亏平衡售价。情景定义（用户可以改参数）：

| 情景 | 定义 |
|---|---|
| 乐观 | 售价 +10%，运费 −10%，退货率相对减半 |
| 基准 | 用户提供的数字原样计算 |
| 压力 | 售价 −10%，运费 +20%，退货率 +5 个百分点，采购成本 +10%（代表汇率或采购价上涨；如果成本已是本地货币成本，用户应把该参数改成 0） |

压力情景还要单独输出四项：价格下降后的利润、退货率变化后的利润、物流费用上涨后的利润、汇率变化后的利润（汇率变化即采购成本 +10% 那一项；成本已是本地货币时写“不适用，成本已是本地货币（MLM 为 MXN / MLB 为 BRL）”）。

**每个情景结果都要标注“模拟结果，不代表实际费用”，尤其是费用来源是用户假设时。**不要把模拟利润描述为真实利润。

## 警告规则

- **运费占售价 >35%**：单独标出警告（低价重货先算运费再谈利润）。
- 净利为负：写清“负毛利”，交给 Skill 6 直接判 NO-GO。
- 首批资金占总预算 >50%：提示资金被单一商品过度占用（交给 Skill 6 的资金效率判断）。
- 任何一项成本为 0 且未说明原因时，写“该项为 0（用户未提供 / 待核实）”，不要默认它真的免费。

## 分析步骤

1. 收齐上游售价（Skills 2–3）和用户成本 / 百分比；缺项先问，或按默认 0 +“待核实”处理并写清。
2. 跑 `profit_estimate.py` 得单件净利、毛利率、盈亏平衡售价。
3. 跑 `operating_profit.py` 得三层利润、首批现金流出、反向推导五项。
4. 跑三情景压力测试（可用 `profit_stress.py` 的情景定义，或按上表手工调参后用同一脚本重算），每情景标注“模拟结果，不代表实际费用”。
5. 检查警告规则（运费占比、负毛利、资金占用），写进输出。
6. 利润结果交给 Skill 6 计利润分（毛利率分档见 Skill 6），本 Skill 不出 verdict。

## 错误处理

| 情况 | 做法 |
|---|---|
| 售价缺失或 ≤0 | 停下，先问用户要售价；不编售价算利润。 |
| 用户未提供任何百分比 | 全部按 0 算，并在输出顶部写清“平台费率 / 税费 / 广告 / 分期均未提供，按 0 计算，结果仅为上限参考，待核实”。 |
| 反向推导分母 ≤0 | 最低可接受售价写“无解（费率 + 目标利润率合计 ≥100%）”，不编一个数。 |
| 供应商报价缺失 | 反向推导照常输出五项上限，供应商对照一节写“供应商报价待核实，无法对照”。 |

- 证据等级（V2.1 五档）：已核实、页面可见、用户提供、待核实、推测。售价以 Skills 2–3 的来源为准；所有成本和百分比以用户提供为准，来源类型写“用户提供”，证据等级写“用户提供”，未提供写“待核实”。
- 税费口径必须写清：已核实的 ISR 2.5% / IVA 8% 只是代扣，不是全部税费成本；不要把 8% IVA 代扣说成总 IVA 成本。Mercado Pago 不代扣州税。**ISR 2.5% / IVA 8% 代扣仅限墨西哥站（MLM），巴西站不适用，巴西税费待核实；巴西站税费 % 为用户提供，默认 0。**
- 局限：本 Skill 算的是基于假设的模拟利润，不是真实利润；实际费用以卖家后台和供应商结算为准；本 Skill 不出 verdict，利润分由 Skill 6 按毛利率分档计。
